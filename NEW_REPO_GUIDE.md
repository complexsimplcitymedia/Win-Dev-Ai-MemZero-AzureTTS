## Architecture

This is infrastructure, not an app. It's meant to be **embedded at the OS level**.

### Three Core Components (As Submodules)

**1. Windows AI Assistant (Cross-Platform Core)**
- Main orchestrator
- Device integration
- Control systems
- Speech recognition
- Configuration management

**2. Azure TTS (Voice Layer)**
- Neural speech synthesis
- Multiple languages
- Local processing option
- MCP server protocol
- Seamless integration

**3. mem0 (Memory/Learning Layer)**
- Persistent conversation memory
- Automatic learning from interactions
- Fact extraction and categorization
- Vector search for context
- The brain of the system

### Supporting Infrastructure

- **11+ MCP Servers** - Extensibility framework
- **Virtual LCD Dashboard** - Real-time monitoring
- **Audio Bridge** - Cross-platform streaming
- **Device Control** - System integration
- **GPU Acceleration** - Via Ollama (AMD, NVIDIA, Intel)
